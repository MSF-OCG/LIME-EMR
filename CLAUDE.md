# LIME EMR

## Git conventions

Commit messages and PR titles start with the change type — `(feat)`, `(fix)` or `(chore)` — followed by the Jira ticket number, then a short description: `(feat) LIME2-1303 Add the Mombasa site`.

Branch names are the ticket number, a slash, then a short hyphenated description: `LIME2-1303/add-mombasa-site`.

When the work has no ticket, leave the ticket number out of commits and PR titles: `(fix) Give Matsapha Data Export the General role baseline`.
